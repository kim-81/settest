Welcome Korea v1.8 검토용

바로 실행: dist\v1.0\WelcomeKorea.exe
설치 파일: dist\v1.0\WelcomeKoreaSetup.exe

맛집찾기에서 시·도 / 시·군·구 / 읍·면·동을 한 줄로 선택합니다.
수원시 팔달구 같은 지역은 시·군·구 목록에서 함께 고릅니다.
아래의 별도 카드 ② 토탈 검색에 홍대 맛집, 신촌 맛집, 명동 맛집 등을 입력하고 지도를 선택하세요.
토탈 검색은 선택 지역이나 음식 유형과 무관하게 입력어 그대로 검색합니다.
음식 유형 아래의 지도 버튼은 선택 지역과 음식 유형으로 검색합니다.
방문 전 영업시간·휴무 / 가격·결제 / 알레르기·식단을 확인하세요.

최초 언어 선택은 한국어 / ENGLISH를 맨 위에 표시하는 50개 국가·지역 드롭다운입니다.
실제 번역은 한국어/영어이며 나머지는 영어 화면으로 안내합니다.
설치 업데이트 전 실행 중인 이전 앱을 닫아 주세요.
사용자 수락에 따라 GitHub 저장소와 이 폴더를 Git으로 동기화합니다.
① 지역 선택에 따른 음식 선택: 지역과 음식 유형을 고른 다음 해당 카드의 지도를 누릅니다.
② 토탈 검색: 원하는 검색어를 입력하고 해당 카드의 지도를 누릅니다.
두 카드는 흰색/연한 청록색 배경으로 나뉘며 제목과 입력 글자를 확대했습니다.
