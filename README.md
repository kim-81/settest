# Welcome Korea — v1.0 배포본

한국 방문 외국인을 위한 Windows 설치형 여행 도우미입니다. 실행 후 첫 화면에서 **50개 국가·지역의 대표 언어 목록**을 드롭다운으로 선택합니다. **한국어, ENGLISH**가 맨 위 두 항목입니다. 홈에는 지도찾기, 맛집찾기, 교통안내, 결제·통신, 언어·여행도움, 저장한 장소의 **6개 카테고리**가 2열 × 3행으로 표시됩니다.

## PC에서 테스트하기

이번 업데이트 배포 파일은 **`dist/v1.0/WelcomeKoreaSetup.exe`**와 **`dist/v1.0/WelcomeKorea.exe`**에 있습니다. 기존 버전을 유지하고 새 버전을 별도 폴더에 제공합니다. 설치 없이 바로 확인하려면 `dist/v1.0/WelcomeKorea.exe`를 실행하세요. 설치 업데이트 전에는 실행 중인 앱을 닫아 주세요. 빌드 스크립트도 `dist/v1.0`에 결과물을 생성합니다.

1. `dist/v1.0/WelcomeKoreaSetup.exe`를 실행합니다.
2. **Install / Update**를 누릅니다.
3. **Launch app** 또는 시작 메뉴의 **Welcome Korea**를 실행합니다.
4. 첫 화면의 **언어 / Language** 드롭다운에서 항목을 선택하고 **시작하기 / Continue**를 누릅니다. 창을 닫으면 앱이 종료됩니다.

실행할 때마다 언어 선택 화면이 나타나며 마지막으로 선택한 항목을 기억합니다. 앱 왼쪽의 **언어 / Language** 버튼으로 다시 선택할 수도 있습니다. 기존 저장 장소와 지역 설정은 유지됩니다.

**현재 번역된 앱 화면은 한국어와 영어입니다.** 다른 언어를 선택하면 번역 준비 중이며 영어 화면을 사용한다는 안내를 선택 화면과 앱 하단에 표시합니다. 50개 항목은 국가·지역별 대표 언어를 선정한 테스트 목록이며 관광객 수에 따른 공식 순위나 50개 고유 언어 목록이 아닙니다. 여러 언어가 쓰이는 국가도 대표 언어 한 가지로 표시했으며 영어처럼 여러 국가가 공유하는 언어는 국가별 항목으로 구분했습니다. 외부 사이트의 언어는 해당 사이트 설정에 따릅니다.

설치 없이 먼저 확인하려면 `dist/v1.0/WelcomeKorea.exe`를 실행하세요. Windows 10/11과 .NET Framework 4.x를 사용하는 버전입니다. 별도 Node/Python 설치나 API 키는 필요 없습니다. 실행 파일은 디지털 서명되지 않은 로컬 개발용 빌드입니다.

## 기능

- **Maps**: 출발지·도착지와 이동방법 입력 후 **네이버지도 → 카카오맵 → 구글맵** 순서로 서비스를 직접 선택합니다. 처음 한 번 검색 결과의 주소를 확인하고 정확한 두 장소를 선택하면 동일한 좌표·이동방법을 유지한 채 지도를 바꿀 수 있습니다.
- **Food**: 전국 시·도 / 시·군·구 / 읍·면·동을 한 줄에서 선택합니다. 음식 유형 12개(전체 포함)로 세 지도에서 검색하고, 별도의 토탈 검색은 입력어 그대로 검색합니다. 수록 식당 6곳과 지역 먹거리 안내 11곳도 같은 조건으로 필터링합니다.
- **Transport**: 공항 이동, 교통카드, 지역 대중교통 안내와 공식 사이트 연결.
- **Essentials**: 해외 카드 결제, SIM/eSIM, 한국 번호 인증, 교통 잔액 안내.
- **Travel Help**: 영어/한국어 문장 카드, 큰 글씨로 보여주기, 한국어 복사, 관광공사 1330 안내 페이지.
- **Saved places**: 이 PC에 저장한 식당을 다시 확인합니다.

한국어 장소명과 문장 카드를 함께 제공합니다. 로그인·한국 휴대전화 인증 없이 사용합니다.

## v1.8 전국 먹거리 검색과 아이콘

지도 서비스 이름 옆에 네이버의 초록 N, 카카오의 노란 지도 핀, 구글의 다색 G 식별 심볼을 직접 그려 넣었습니다. 지도찾기와 맛집 지도 검색 버튼에 함께 표시됩니다.

전국 지역은 행정표준코드관리시스템에서 내려받은 존재 상태의 법정동 코드 20,560건을 사용합니다. 행정동 목록과는 다를 수 있으며 원본에 없는 중간 단계는 건너뜁니다. 예: 경기도 / 수원시 팔달구 / 팔달로1가, 충청북도 / 단양군 / 단양읍. 별도의 세부 구·맛집골목·리 선택란은 제거했습니다. 세종시는 시·군 선택 없이 읍·면·동을 고릅니다. 상위 지역을 바꾸면 하위 선택을 초기화합니다.

전체 음식, 국물류, 볶음류, 분식류, 구이류, 면류, 밥·백반, 해산물, 찜·조림, 양식, 카페·디저트, 채식을 각각 그림 심볼과 함께 표시합니다. 지역·음식 유형은 지역별 지도 검색 조건에 반영되며 최근 지역/유형은 PC에 저장됩니다.

**전국 모든 식당을 앱에 수록한 데이터베이스는 아닙니다.** 전국 어디든 선택 조건대로 지도 검색을 열 수 있고, 앱 내부 소개는 출처를 확인한 기존 식당 6곳과 시장·먹거리골목 11곳입니다. 별도의 토탈 검색에 홍대 맛집, 신촌 맛집, 명동 맛집 등 원하는 문구를 입력하면 지역·음식 필터와 관계없이 검색합니다. 지역명은 한국 공식 명칭으로 표시하며 영문 화면에서도 검색에 같은 명칭을 사용합니다. 실시간 업소·영업 여부와 검색 결과는 지도 서비스에서 확인합니다. 출처와 데이터 처리 기준은 `data/SOURCES.md`에 있습니다.

## 디자인 및 길찾기

홈 6개 카테고리와 전체 페이지 제목·사이드 메뉴에 같은 선 스타일의 심볼을 적용했습니다. 핀·식기·교통·카드·말풍선·북마크를 직접 그리며 외부 아이콘 폰트나 이미지 다운로드에 의존하지 않습니다. 홈 카드는 둥근 테두리와 선택/포커스 효과를 제공합니다.

지도찾기에서 **출발지는 여기에 입력**, **도착지는 여기에 입력** 안내에 따라 두 장소를 입력하고 이동방법을 선택한 뒤 **네이버지도 / 카카오맵 / 구글맵** 중 하나를 누르세요. 장소 확인 창의 **두 장소 검색**을 누르면 Photon에서 후보를 찾습니다. 주소를 확인해 출발지 1개와 도착지 1개를 각각 선택한 뒤 확인하세요. 이름만으로 장소를 자동 확정하거나 좌표가 없는 잘못된 경로를 열지 않습니다.

실제 경로·소요시간·환승 정보는 기본 브라우저의 선택한 지도에 표시됩니다. 지도만 바꾸거나 이동수단을 바꿀 때는 확인한 장소를 재사용합니다. 입력 텍스트가 바뀌면 잘못된 좌표가 남지 않도록 장소를 다시 확인합니다. 앱 안의 이동 계획은 검색 요청 요약이며 실제 계산된 경로나 지도는 아닙니다.

이동수단 연결:

- 대중교통: 네이버 `transit`, 카카오 `traffic`, 구글 `transit`. 버스·지하철 세부 필터는 해당 지도에서 조절합니다.
- 택시: 네이버·카카오 `car`, 구글 `driving`. 차량 경로이며 호출·실시간 요금 기능은 아닙니다.
- 도보: 네이버·카카오 `walk`, 구글 `walking`.
- 자전거: 네이버 `bike`, 카카오 `bicycle`, 구글 `bicycling`.

네이버에는 웹 경로 공유 형식에 맞춘 Web Mercator 좌표를, 카카오에는 [공식 웹 길찾기 URL](https://apis.map.kakao.com/web/guide/#routeurl) 형식의 위도·경도를, 구글에는 [공식 Maps URL](https://developers.google.com/maps/documentation/urls/get-started) 형식의 위도·경도를 전달합니다. 서울시청 → 덕수궁 단거리 도보 예제로 네이버와 카카오에서 실제 경로를 확인했습니다. 각 서비스의 지원 범위, 입구 위치, 도로 연결, 공사·통행 제한 등에 따라 경로가 없거나 달라질 수 있습니다. 특히 Google 자체의 한국 내 도보·자전거 미지원은 앱이 해결할 수 없으므로 네이버·카카오를 먼저 제시합니다. 지도 오류나 서비스 중단을 100% 방지한다고 보장하지 않습니다.

## 장소 검색 및 개인정보

장소 검색은 [Photon 공개 API](https://photon.komoot.io/)와 OpenStreetMap 데이터를 이용합니다. 장소 확인 창에서 검색 버튼을 눌렀을 때만 두 검색어를 Photon에 전달합니다. 후보는 자동 선택하지 않으며 주소와 좌표를 보고 사용자가 고릅니다. 데이터는 [OpenStreetMap 기여자](https://www.openstreetmap.org/copyright)에게 귀속되며 ODbL 조건이 적용됩니다.

이 버전은 개인 테스트용 소규모 사용을 전제로 합니다. 자동완성·주기적 조회 없이 수동 검색만 수행하며, 요청 간격과 메모리 캐시를 적용했습니다. Photon 공개 서버는 대규모 사용 시 제한될 수 있고 가용성을 보장하지 않습니다. 배포 규모가 커지면 별도 검색 서비스나 자체 서버로 전환해야 합니다. WELCOME_KOREA_PHOTON_URL 환경변수로 호환되는 HTTPS Photon API 주소를 설정할 수 있습니다.

이전 Framework HTTPS 호환성 문제를 피하기 위해 Windows 기본 curl.exe를 숨겨진 프로세스로 실행합니다. 셸을 거치지 않고 인코딩한 HTTPS URL만 전달하며 인증서 검증을 해제하지 않습니다. Windows 10 1803 이상 또는 Windows 11의 기본 curl.exe가 필요합니다. 다운로드나 보안 설정 변경은 하지 않습니다.

## 온라인과 오프라인 범위

식당 소개, 기본 안내, 문장 카드와 저장 목록은 앱에 포함되어 오프라인으로 볼 수 있습니다. 지도·길찾기·출처·추가 검색은 기본 브라우저를 열며 인터넷이 필요합니다. 검색어는 해당 외부 서비스로 전달됩니다. 위치는 자동으로 수집하지 않습니다.

**맛집 소개는 2026-10-28 온라인 조사로 저장한 자료이며 실시간 검색 결과나 실시간 순위가 아닙니다.** Search web 버튼은 지역과 검색어를 이용해 브라우저에서 추가 검색합니다. 임의 지역의 식당을 실시간으로 앱 안에서 수집·요약하는 서버 기능은 포함하지 않았습니다.

메뉴 가격·영업시간은 변경 가능하여 최신 출처 확인을 안내합니다. 개별 식당의 해외 카드·영어 서비스·할랄 인증·알레르기 안전은 검증되지 않았습니다. 한국 내 Google 지도 경로 지원은 이동 수단에 따라 달라질 수 있어 대체 지도 링크를 제공합니다. 앱 내 결제·예약·자동 번역·긴급 신고 기능은 없습니다.

## 설치 및 제거

현재 사용자용 설치 위치: `%LOCALAPPDATA%\Programs\WelcomeKorea`.

시작 메뉴 바로가기와 Windows 설치된 앱 목록에 등록합니다. 제거하려면 Windows 설치된 앱의 Welcome Korea, 시작 메뉴의 Uninstall Welcome Korea, 또는 설치 파일의 Uninstall을 사용합니다. 업데이트·제거 전에 실행 중인 앱을 종료하세요. 설치·제거는 전원 설정 등 다른 Windows 설정을 변경하지 않습니다.

저장 목록 및 선택 지역: `%LOCALAPPDATA%\WelcomeKorea\preferences.json`. 제거해도 보존합니다. 설치된 제거 프로그램을 실행하면 잠긴 파일을 처리하기 위해 임시 폴더에 제거 도우미 복사본이 남을 수 있으며 Windows 임시 파일 정리로 지울 수 있습니다.

## 빌드 및 테스트

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Windows 기본 .NET Framework C# 컴파일러로 앱·설치 파일·테스트 실행 파일을 만듭니다. 외부 패키지 다운로드는 없습니다. `dist/v1.0/SHA256SUMS.txt`에 실행 파일 해시를 기록합니다.

검증 항목: 자료 검색/지역 필터, URL 인코딩, 링크 제한, 로컬 저장/불량 데이터 복구, 7개 화면 생성, 작업 폴더 안에서 설치 파일 추출·시작 메뉴 형식의 바로가기 생성·업데이트·제거, 사용자 파일 보존. 테스트는 실제 사용자 설치 위치나 설치된 앱 레지스트리를 수정하지 않습니다.

수동 확인: 설치 파일 실행 → 설치 → 앱 실행 → 지역 변경 → 맛집 저장 → 재실행 → 지도/출처 브라우저 연결 → 문장 카드 → 제거. 실제 인터넷 링크는 서비스 변경으로 동작이 달라질 수 있습니다.

방문자 안내는 🕒 영업시간·휴무, 💳 가격·결제, 🥜 알레르기·식단 세 항목으로 간추렸습니다. 앱의 기술적인 지역 데이터 소개는 제거했고 출처 문서에 보관합니다.

## v1.8 검색 영역 구분

상단 흰색 카드 ① 지역 선택에 따른 음식 선택: 시·도/시·군·구/읍·면·동 → 음식 유형 → 지도 선택 순서입니다.
하단 연한 청록색 카드 ② 토탈 검색: 홍대 맛집 등의 자유 검색어 → 지도 선택 순서이며 ①번 필터와 독립적입니다.
번호가 있는 제목과 설명을 추가하고 제목 17pt, 설명·지역 선택 11pt, 검색 입력 12pt, 음식 버튼 10.5pt로 확대했습니다. 긴 페이지는 아래로 스크롤해서 확인할 수 있습니다.

## v1.8 화면 디자인 정리

우측 상단 서울 지역 선택을 모든 페이지에서 제거했습니다. 서울 기본 지역에 의존하던 바로가기 대신 지도찾기에서 목적지를 직접 선택합니다.
본문은 11~12pt, 카드 제목은 16~17pt 중심으로 조정했습니다. 설명은 한국어·영어 모두 문장이 끝날 때 다음 줄에서 이어집니다. 번호·소수·URL과 사용자가 입력한 검색어는 보존합니다.
각 화면에 한국 산수·한옥 지붕·보름달·매화 모티프를 직접 그린 벡터 배경을 적용했습니다. 지도는 녹색, 음식은 흙빛, 교통은 푸른색, 결제·통신은 보라색, 여행 도움은 매화색, 저장 장소는 금빛으로 구분합니다. 글은 흰색 카드 위에 배치하고 페이지 심볼·안내 이모티콘을 함께 사용합니다. 외부 사진·로고 파일이나 이미지 생성 서비스는 사용하지 않았습니다.
긴 화면은 스크롤하여 읽습니다. Windows 글꼴 및 화면 배율에 따라 실제 문장 줄 수는 달라질 수 있습니다.

## GitHub와 로컬 관리

사용자가 정리한 배포 폴더는 `dist/v1.0`이며 앱 내부 버전은 오늘까지 개발한 최신 1.8입니다. 소스·실행·설치 파일을 함께 관리합니다. 관리 폴더는 `C:\Users\User\Desktop\github\settest`입니다. 동기화 방법은 `SYNC.md`를 참고하세요.
